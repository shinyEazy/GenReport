# AXIOM LaTeX Report Skill

Use this guide when the user asks for a long report, publication-style analysis, PDF report, Vietnamese report, or a document that should look polished rather than like a chat answer.

## When to use LaTeX

Use LaTeX when the user asks for a PDF, long-form report, formal analysis document, paper-style output, or high-quality deliverable. If the user only asks for a quick answer or lightweight notes, use markdown instead.

Before writing the final report, inspect any generated files. Include a figure
only when it communicates a directly supported finding more clearly than text
or a compact table. Do not put all charts into one generic visualization section.

## Writing Style

Write like an analyst explaining evidence, not like a template. Prefer cohesive paragraphs over bullet lists. Use bullet points sparingly for compact summaries, definitions, or action items. Avoid generic headings such as "Executive Summary" unless the user explicitly asks for them.

Make the report proportional to the available evidence. A simple or narrow
input may warrant only a concise report with a small number of sections. Add
background, implications, caveats, recommendations, or detail only when they
are directly supported by the supplied evidence or explicitly requested by the
user. Never add generic filler to make a report appear more substantial.

Charts are optional, never required. Create a chart only when it makes a
directly supported finding about a pattern, comparison, distribution, or trend
clearer than text or a compact table. Do not create decorative, redundant, or
weakly supported charts. If the data is too small, has only one
observation/category, has no meaningful comparison, or is primarily
qualitative, use text or a compact table instead. It is valid for a report to
contain no charts.

Use section titles that state findings, for example:

- "Location and area explain most of the price spread"
- "Pollution spikes cluster around Mong Kok and commuting days"
- "The model performs well on mid-range homes but underestimates premium properties"

## Recommended LaTeX Template

The templates below are layout examples, not mandatory outlines. Use only the
sections, tables, and figures that the supplied evidence supports; omit every
placeholder or example section that does not apply.

For English reports, use `pdflatex`. For Vietnamese reports, use `xelatex` with `fontspec` and a Vietnamese-capable font.

The AXIOM logo is bundled with this skill under `./res/logo.png`. In local mode, the stable compile path is `.skills/res/logo.png` relative to the current working directory. Use that path in generated reports so the logo remains an internal resource and is not uploaded as a user-visible generated file.

## Input-file citations

When supplied input files are used, include an inline citation for every substantive fact, statistic, comparison, or conclusion. Number sources by the `AVAILABLE INPUT FILES` order: use `[1]` for one source and `[1, 2]` for multiple sources. End the PDF with a `References` heading listing every supplied input file with the same numbers; never invent a source.

```latex
Revenue increased by 12\% [1].

\section*{References}
[1] sales.csv\\
[2] notes.pdf
```

Do not simplify or remove the AXIOM website link from the page header. Every generated LaTeX report should keep the subsequent-page header exactly as `Generated by AXIOM: \url{https://AXIOM.com.ai}` unless the user explicitly asks to remove branding.

## Table Rules

Tables must not overflow the page width. Avoid raw `tabular` with many columns. Prefer `tabularx` with `\textwidth`, compact numeric columns, and one or more flexible text columns. Use smaller font only when needed.

Good default table:

```latex
\begin{table}[H]
\centering
\small
\caption{District-level air quality summary}
\begin{tabularx}{\textwidth}{lrrrrY}
\toprule
District & PM2.5 & PM10 & NO2 & AQI & Interpretation \\
\midrule
Mong Kok & 54.7 & 86.2 & 67.9 & 111.7 & Highest average exposure; prioritize deeper temporal checks. \\
Tai Po & 28.6 & 46.2 & 34.7 & 59.6 & Cleaner baseline with fewer high-risk days. \\
\bottomrule
\end{tabularx}
\end{table}
```

For many columns, rotate or scale safely. Use this only when the table is mostly numeric and cannot be summarized:

```latex
\begin{table}[H]
\centering
\scriptsize
\caption{Model diagnostics across feature groups}
\resizebox{\textwidth}{!}{%
\begin{tabular}{lrrrrrr}
\toprule
Model & R2 & RMSE & MAE & Bias & CV Mean & CV Std \\
\midrule
Linear regression & 0.68 & 732000 & 521000 & -12000 & 0.64 & 0.05 \\
Ridge regression & 0.69 & 721000 & 514000 & -9000 & 0.65 & 0.04 \\
\bottomrule
\end{tabular}
}
\end{table}
```

For long row-oriented tables, use `longtable` so the table can continue across pages:

```latex
\small
\begin{longtable}{p{0.22\textwidth}p{0.52\textwidth}r}
\caption{Important observations and supporting evidence}\\
\toprule
Topic & Finding & Value \\
\midrule
\endfirsthead
\toprule
Topic & Finding & Value \\
\midrule
\endhead
Price drivers & Area remains the strongest positive predictor after standardization. & 0.42 \\
Risk segment & High-AQI days concentrate in the central commercial districts. & 31\% \\
\bottomrule
\end{longtable}
```

If a table still looks too wide, summarize it into fewer columns instead of forcing it onto the page. A clear compact table is better than a dense unreadable one.

## Figure Rules

Use full-width figures for most charts:

```latex
\includegraphics[width=\textwidth]{./data/workspaces/<conversation_id>/chart.png}
```

For smaller diagnostic figures, use `0.82\textwidth`. Always use local workspace local paths, not OSS URLs or proxy URLs, when compiling PDF reports.

## Compile Commands

English report:

```bash
pdflatex -interaction=nonstopmode -halt-on-error -output-directory ./data/workspaces/<conversation_id> ./data/workspaces/<conversation_id>/report.tex
```

Vietnamese or mixed Vietnamese/English report:

```bash
xelatex -interaction=nonstopmode -halt-on-error -output-directory ./data/workspaces/<conversation_id> ./data/workspaces/<conversation_id>/report.tex
```

Keep the source in UTF-8, use `fontspec`, and choose a font with full Vietnamese support. Localize the title page, summary, section headings, dates, captions, table labels, and chart text. Preserve code, column names, filenames, and technical terms when translation would reduce clarity.

Run the compiler twice if the document has a table of contents, references, or cross-references.

## Defaults

If the user does not provide an author, use `AXIOM`.

If the user does not specify a report language, match the user's language. For Vietnamese reports, use `xelatex` with `fontspec` and a Vietnamese-capable font.
